## ⚙️ Kisi Bhi Project Ko Kaise Run Karein

### Prerequisites
Aapke system mein ye installed hone chahiye:
- **Node.js** (v14 ya usse upar)
- **MongoDB** (local ya MongoDB Atlas)
- **npm** ya **yarn**

### Installation Steps

```bash
# 1. Repository clone karein
git clone https://github.com/your-username/mern-projects.git

# 2. Kisi bhi project folder mein jaayein
cd E-Commerce-App   # Example

# 3. Backend setup karein
cd backend
npm install

# 4. Environment variables setup karein
# .env file banayein aur apni values add karein:
# MONGO_URI=your_mongodb_connection_string
# JWT_SECRET=your_secret_key
# PORT=5000

# 5. Backend server start karein
npm run dev

# 6. Naye terminal mein frontend setup karein
cd ../frontend
npm install

# 7. Frontend start karein
npm run dev
```

## 🧰 Tech Stack

### Frontend
- ⚛️ **React 18+** - UI library
- ⚡ **Vite** - Build tool
- 🧭 **React Router DOM** - Client-side routing
- 🔄 **Redux Toolkit** - State management
- 🎨 **Tailwind CSS** / Material-UI - Styling

### Backend
- 🟢 **Node.js** - Runtime environment
- 🚂 **Express.js** - Web framework
- 🍃 **MongoDB** - Database
- 🔐 **JWT** - Authentication
- 🔒 **bcrypt** - Password hashing

## 🔐 Environment Variables

Har project ke `backend` folder mein `.env` file banayein:

```env
# Database
MONGO_URI=mongodb://localhost:27017/your_db_name
# or
MONGO_URI=mongodb+srv://username:password@cluster.mongodb.net/dbname

# JWT Secret
JWT_SECRET=your_super_secret_key_here

# Server Port
PORT=5000

# Frontend URL (for CORS)
CLIENT_URL=http://localhost:5173
```
